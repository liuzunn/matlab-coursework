# MATLAB 课程实验

大学 MATLAB 课程的实验代码，加上几个常用的组合数学/概率函数。

## 实验内容

| 文件 | 实验内容 |
| :--- | :--- |
| `exp8_1.m` | 占位文件 |
| `exp8_2.m` | 描述统计：10 个零件直径的均值、中位数、方差、标准差、极差 |
| `exp8_3.m` | 生成 50×5 正态样本，求协方差与相关系数矩阵，手算双尾 t 检验 P 值并筛出 `p<0.05` 的变量对 |
| `exp9_1.m` | 复数矩阵运算：实部/虚部、模、辐角、共轭，以及逐元素的 sin、幂、对数、指数 |
| `exp9_2.m` | 复平面参数曲线：`z = t + i·t²` 与 `z = t + i·e^t·sin t` |
| `exp9_3.m` | 用 `residue` 对两个有理分式做部分分式分解与留数分析 |
| `exp10_4.m` | 符号傅里叶变换：`f(x) = 4sin(3x)/x` |
| `exp10_5.m` | 符号拉普拉斯变换：`g(t) = e^{-4t}sin t + (e^{-2t}+2t-1)/4` |

实验 9 整块在练 **复变函数**，实验 10 练 **符号运算**（Fourier / Laplace 变换）。

## 组合数学与概率

| 文件 | 功能 |
| :--- | :--- |
| `zuhe.m` | 组合数 `C(n,k)`，用排列数除以 `k!` 实现 |
| `pailie.m` | ⚠️ **有问题** —— 见下方说明 |
| `fcircle.m` | 输入半径，返回圆面积与周长 |
| `binomial_prob.m` | 二项分布：算胜 / 负 / 平的概率（阈值 5 次成功） |
| `probability_calculation.m` | 先由均匀分布求单次成功概率，再算 n 次中至少 `k_min` 次成功的概率 |
| `redball.m` | 空文件（未完成） |

> ⚠️ **`pailie.m` 是坏的**：它的函数名声明成了 `zuhe`，函数体里又调用 `pailie`，等于自己调用自己。当时应该是由 `zuhe.m` 复制过来忘了改。所以这个目录里实际上 **没有可用的排列函数**。

另外 `zuhe.m` 依赖 `pailie`，所以这两个函数目前都不能正常工作 —— 组合数实际是用 `nchoosek` 或 `factorial` 手算的。

## 运行环境

- MATLAB R2020a 及以上
- `exp10_4.m`、`exp10_5.m` 需要 **Symbolic Math Toolbox**
- 其余脚本只用到基础 MATLAB
